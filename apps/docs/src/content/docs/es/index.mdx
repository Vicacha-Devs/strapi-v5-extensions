## Pilares Fundamentales

<CardGrid stagger>
  <Card title="14 Plugins de Producción para Strapi v5" icon="puzzle">
    Construidos nativamente sobre la Document Service API (`strapi.documents(uid)`), Design System
    v2 y compilación dual Admin + Server con `@strapi/sdk-plugin`.
  </Card>
  <Card title="Puentes Automáticos entre Plugins" icon="random">
    `events` y `bookings` se registran automáticamente en `calendar`; `donations` emite recibos
    firmados vía `certificates`; `islam` sincroniza el calendario Hijri y alertas en `inbox`.
  </Card>
  <Card title="Seguridad Criptográfica y Webhooks" icon="approve-check-circle">
    Firmas digitales Ed25519, validación HMAC-SHA256 en tiempo constante, protección contra
    SSRF/Path Traversal y enmascaramiento de datos personales (PII).
  </Card>
  <Card title="Paridad i18n en 13 Idiomas y RTL" icon="translate">
    Traducciones completas para `en`, `es`, `ar` (RTL), `tr`, `fr`, `de`, `pt`, `it`, `nl`, `pl`,
    `id`, `ur` (RTL) y `zh`, más calendarios secundarios Hijri, Hebreo y Persa.
  </Card>
</CardGrid>
