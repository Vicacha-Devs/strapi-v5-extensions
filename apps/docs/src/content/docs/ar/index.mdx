## الركائز الأساسية للمنظومة

<CardGrid stagger>
  <Card title="14 إضافة جاهزة للإنتاج على Strapi v5" icon="puzzle">
    مبنية بالكامل باستخدام Document Service API (`strapi.documents(uid)`) ونظام التصميم Strapi
    Design System v2 وبنية الحزم المزدوجة.
  </Card>
  <Card title="جسور تكامل تلقائية بين الإضافات" icon="random">
    تسجيل تلقائي للفعاليات والحجوزات داخل التقويم الموحد، وإصدار إيصالات تبرع موقعة رقمياً عبر
    الشهادات، ومزامنة الهلال الهجري والتنبيهات.
  </Card>
  <Card title="تأمين التشفير الرقمي وحماية Webhooks" icon="approve-check-circle">
    توقيع Ed25519 الرقمي، والتحقق من تواقيع HMAC-SHA256 بزمن ثابت، والحماية من ثغرات SSRF وعبور
    المسارات وتعمية البيانات الشخصية.
  </Card>
  <Card title="دعم كامل لـ 13 لغة واتجاه RTL والتقويم الهجري" icon="translate">
    تكافؤ كامل في ترجمات لوحة التحكم لـ 13 لغة مع دعم كامل للغة العربية والأردية (RTL) وتقويم أم
    القرى الهجري والعبري والفارسي.
  </Card>
</CardGrid>
