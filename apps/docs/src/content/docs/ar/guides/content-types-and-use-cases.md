## أين تجد كيانات أنواع المحتوى في Strapi v5

| الموقع في Strapi v5                           | المسار / الواجهة البرمجية                               | الوظيفة والاستخدام                                                                                       |
| :-------------------------------------------- | :------------------------------------------------------ | :------------------------------------------------------------------------------------------------------ |
| **مدير المحتوى (Content Manager)**            | `/admin/content-manager/collection-types/plugin::<uid>` | تصفح وتحرير 21 مجموعة مرئية (`Booking`، `Event`، `Issued Certificate`، `Publication`، إلخ).             |
| **منشئ أنواع المحتوى (Content-Type Builder)** | `/admin/plugins/content-type-builder`                   | استعراض المخططات وإرفاق مكونات `shared.seo` و `shared.open-graph` والحقول المخصصة `rrule` و `currency`. |
| **مساحات عمل الإضافات**                        | `/admin/plugins/<plugin-id>`                            | واجهات الإدارة المتخصصة (التقويم الموحد، إصدار الشهادات الرقمية، مواقيت الصلاة، صندوق الوارد).            |
| **واجهة خدمة المستندات (Document Service)**   | `strapi.documents("plugin::<id>.<entity>")`             | الاستعلام والإنشاء والتحديث برمجياً مع دعم توسيع المخططات عبر `config.schemaExtensions`.                    |
