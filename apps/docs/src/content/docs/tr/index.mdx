## Temel Mimari Sütunlar

<CardGrid stagger>
  <Card title="14 Üretime Hazır Strapi v5 Eklentisi" icon="puzzle">
    Strapi v5 Document Service API (`strapi.documents(uid)`), Design System v2 ve
    `@strapi/sdk-plugin` çift paket mimarisi üzerine inşa edilmiştir.
  </Card>
  <Card title="Sıfır Yapılandırmalı Eklenti Köprüleri" icon="random">
    `events` ve `bookings` otomatik olarak `calendar` içine kaydolur; `donations` `certificates`
    üzerinden imzalı makbuz üretir; `islam` Hicri takvim ve `inbox` uyarılarını eşitler.
  </Card>
  <Card title="Kriptografik Güvenlik ve Webhook Koruması" icon="approve-check-circle">
    Ed25519 dijital imzalar, sabit zamanlı HMAC-SHA256 webhook doğrulaması, SSRF/Path Traversal
    koruması ve tuzlanmış PII maskeleme.
  </Card>
  <Card title="13 Dilde Yönetim Arayüzü ve RTL Desteği" icon="translate">
    `en`, `es`, `ar` (RTL), `tr`, `fr`, `de`, `pt`, `it`, `nl`, `pl`, `id`, `ur` (RTL) ve `zh`
    dillerinde tam çeviri eşitliği ve Hicri/İbranice/Farsça ikincil takvimler.
  </Card>
</CardGrid>
